# Billick_UB-Canteen-Pre-Order-App
CSSOFT1 REPO QUIZ

specify user
6 issues ( in user story format)
1. menu page
  - as a customer I want to view the available food and drinks with their prices  so that I can choose what I want to order.
2. order form
  - as a customer I want to be able to add, remove, or edit my orders so that I can easily change my order before submitting it.
3. log in screen
  - as a customer I want to to be able to use my account credentials so that I can access my account and place Pre-Orders.
4. pay with gcash
  - as a customer I want to pay for my Pre-Orders using GCash so that I can make convenient cashless transaction.
5. pick up alert
  - as a customer I want to receive a notification when my Pre-Order is ready for pickup so that I know when to claim my order from the canteen.
6. daily sales report
  - as a business owner I want to be able to get or generate a daily sales report so that I am able to get data from the statistics from the report
